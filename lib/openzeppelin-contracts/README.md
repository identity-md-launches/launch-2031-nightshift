This directory vendors the unmodified Solidity dependency closure of ERC20 from
OpenZeppelin Contracts **v5.1.0**, plus its MIT license.

Source: https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.1.0

Only ERC20, IERC20, IERC20Metadata, Context and draft-IERC6093 are included.
These are ordinary files; no package installation, git submodule, or network
access is needed to compile this project.
